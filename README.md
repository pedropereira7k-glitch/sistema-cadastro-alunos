# Sistema de Cadastro de Alunos
## Sobre
Este projeto é um sistema de console desenvolvido em C# para cadastrar, consultar, remover e analisar alunos em uma turma. Ele permite armazenar nome, idade e nota de cada aluno, oferecendo operações básicas de gerenciamento de dados.
## Funcionalidades

* Cadastrar alunos
* Listar todos os alunos cadastrados
* Buscar aluno pelo nome
* Remover aluno pelo nome
* Calcular a média geral da turma
* Exibir a maior nota cadastrada
* Validar dados de entrada para nome, idade e nota

## Tecnologias

* C#
* .NET

## Como executar

1. Clone o repositório: `git clone https://github.com/pedropereira7k-glitch/sistema-cadastro-alunos.git`
2. Acesse a pasta do projeto: `cd sistema-cadastro-alunos`
3. Execute a aplicação: `dotnet run`

## O que esse projeto demonstra

* Programação Orientada a Objetos (classes, objetos, encapsulamento)
* Coleções genéricas (List<T>)
* Validação robusta de entrada do usuário
* Organização de código por responsabilidade
* Estruturas de repetição e condicionais
* Manipulação de dados em memória

## Exemplo de uso
Ao executar o programa, o usuário verá um menu com opções para cadastrar um novo aluno, listar alunos, buscar aluno por nome, remover aluno, calcular a média da turma e ver a maior nota.
